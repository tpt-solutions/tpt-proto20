# Changelog

All notable changes to `tpt20-stdlib` are documented here.

## [Unreleased]

### Added
- Initial standard library types (Phase 9, spec §15)
- `Timestamp`, `Duration`, `Empty`
- `Any`, `Struct`, `Value`, `ListValue`
- `FieldMask`, `UUID`, `Decimal`, `Money`, `Interval`
- `Pagination`, `ErrorDetail`
- Wrapper types: `BoolValue`, `BytesValue`, `DoubleValue`, `FloatValue`, `Int32Value`, `Int64Value`, `UInt32Value`, `UInt64Value`, `StringValue`
- Stability/versioning policy (`STABILITY.md`)
- Canonical `.tpt` schemas for all standard types
