# Allowed inputs

Per the clean-room policy (spec §25.1), the following inputs are permitted when
developing `tpt-proto20`:

- The project's own design document, `spec.txt`.
- Original design notes authored by project contributors.
- Original tests and test vectors created by project contributors.
- Publicly documented wire-format and schema conventions described in
  `spec.txt`.

# Disallowed inputs

- Upstream implementation source code for comparable serialization/RPC systems.
- Proprietary or third-party implementations of similar systems.
- Copied code-generation templates from other projects.
- AI prompts (or their outputs) containing upstream source code.
