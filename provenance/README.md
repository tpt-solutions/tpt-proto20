# Provenance

This directory records the clean-room provenance and contribution history for
`tpt-proto20`, in support of the policies described in
[`CONTRIBUTING.md`](../CONTRIBUTING.md) and `spec.txt` §25.

## Policy

- All implementation work derives from the project's own public specification
  (`spec.txt`) and original contributor design notes/tests.
- Upstream implementation source code for comparable systems is never used as
  an input (see clean-room policy, spec §25.1).
- AI-assisted contributions are recorded with their method and reviewed by a
  human (spec §25.2).

## Contents

- `allowed_inputs.md` — the set of inputs permitted for this project.
- `decisions.md` — recorded design decisions and their rationale.
